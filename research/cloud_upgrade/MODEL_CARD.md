## 使用边界

这是**标注回合范围内**的击球时刻检测，不是完整视频端到端准确率。
当前没有验证休息、捡球、热身和剪辑期间的每分钟误报；短间隔双打连击可能被 0.30 秒 NMS 压掉。
现有测试比赛过去已经使用过，不能称全新盲测。隔离比赛也可能被其他旧组件接触过，
“隔离”特指本轮 HitNet 训练和选模。

下一步发布验收：连续录像负样本、真实球馆、双打四人击球归属、BST 球种分类联测、
云 GPU 运行时与成本。没有据此宣称“世界第一”或“单打双打均已顶尖”。

原始证据：`data_manifest.json`、`selection.json`、`comparison.json`、`side_audit.json`、
对应 run 的 `config.json` / `metrics.jsonl` / `trainer_snapshot.py`。重新训练必须建立新实验，
不根据已经打开的测试结果反复选权重。
